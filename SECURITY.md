# Security

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on the
[Security tab](https://github.com/hraness/presence/security/advisories/new), not in a public issue.
presence only reads system state and never writes, sends or stores anything, but reports about
anything it reads, how releases are built, or how it could be made to mislead a scheduler are
welcome. We aim to reply within a week and will credit reporters who want it.
